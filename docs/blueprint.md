# **App Name**: Nizam Afraad

## Core Features:

- Dashboard: Provide an overview of personnel data with key metrics and quick actions.
- Personnel List Management: Enable the creation, viewing, and modification of personnel records.
- Advanced Personnel Search: Enhance the search functionality to allow users to use semantic understanding of query criteria to produce higher quality search results.
- Reporting: Allow users to generate personnel reports and view statistics.
- User management: Allow users to manage other users.
- Notifications: Display system notifications to alert administrators to important and/or time-sensitive events.

## Style Guidelines:

- Primary color: Indigo (#4F46E5) for a professional and modern feel.
- Background color: Light gray (#F9FAFB) for a clean, minimal appearance.
- Accent color: Teal (#008080) to highlight important actions and information. Avoid teal.
- Body and headline font: 'Tajawal' (sans-serif) for clear, readable text in Arabic.
- Use Feather Icons for a consistent and modern look.
- Implement a left-to-right (LTR) layout, as explicitly specified.
- Subtle transitions and animations to enhance user experience.
